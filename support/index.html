Peekaboo Support

Help with previewing 3D models, game art, code, notebooks and music in Finder.

Getting started

  1. Open Peekaboo once after installing it. This tells macOS about its previews. You can quit it afterwards; the previews keep working.
  2. In Finder, select a file and press Space.
  3. Switch a Finder window to icon view to see thumbnails of models, sprites, maps and paintings.

Peekaboo needs macOS 14 Sonoma or later.

If a preview doesn't appear

Reset Quick Look

Open Peekaboo and click Reset Quick Look. This clears macOS's preview cache, which can hold on to an older preview. Then try the file again.

Check that the extensions are on

Open System Settings → General → Login Items & Extensions, find Quick Look, and make sure the Peekaboo extensions are switched on.

Check the file type is switched on

Open Peekaboo and make sure the file type is ticked. Switching a type off hands it back to macOS's own preview.

Thumbnails still show the old icon

Finder caches thumbnails. Click Reset Quick Look, then close and reopen the Finder window. Very large files show a plain icon on purpose, so Finder stays quick.

"Too large to preview"

Peekaboo stops at a size limit for each file type (for example 500 MB for 3D models), so a huge file never freezes Finder. The file itself is fine.

Music doesn't play

MIDI and tracker songs play in Quick Look's own player: press its play button. They stop when you move to another file. SoundFonts stay silent until you play the on-screen keyboard (click the keys or type A–K).

Markdown images are missing

Images stored next to the Markdown file show straight away. Images linked from the web need an internet connection.

Privacy

Everything happens on your Mac. Peekaboo has no accounts, collects no data, and your files never leave your Mac. Read the full privacy policy.
